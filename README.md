# Essentials Bedrock

A comprehensive utility and management addon for Minecraft Bedrock Edition servers.

## Features

- Player Management
- Economy System
- Teleportation Commands
- Home System
- Warps
- Chat Management
- And much more!

## Installation

1. Download the latest release
2. Import the behavior pack into your world
3. Enable required permissions
4. Restart your world/server

## Commands

See the [Commands Documentation](docs/commands.md) for a full list of available commands.

## Configuration

Configuration files can be found in the behavior pack's files. Edit them to customize the addon's functionality.
